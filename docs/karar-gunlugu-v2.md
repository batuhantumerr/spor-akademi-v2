# Karar günlüğü — v2 eklemeleri

[Proje dokümanındaki](proje-dokumani.md) DEC-001 – DEC-096 aynen geçerlidir. Bu dosya, bu repoda (spor-akademi-v2) alınan yeni kararları içerir. Sahip yokken agent'ın aldığı kararlar **Proposed** durumundadır; sahip onaylayınca **Accepted** olur. DEC-099 – DEC-368 sahip tarafından 2026-11-10'da [onay listesindeki](pazartesi-onay-listesi.md) önerilerle birlikte toplu kabul edildi.
